# AI-Powered Alcohol Label Verification App (TTB Compliance Prototype)

An accessible, high-speed compliance tool prototype built for TTB agents to automate routine data verification between COLA application forms and physical alcohol beverage labels.

## 🚀 Live Demo
- **Deployed Application URL:** https://cola-check.vercel.app

---

## ✨ Key Features & Stakeholder Alignment

* **Sub-5-Second Latency:** Designed for rapid feedback loops under 5 seconds to eliminate manual review bottlenecks and prevent agent backlogs.
* **Accessible, High-Contrast UI:** Built with large controls and high-contrast typography, catering to compliance staff across all levels of technical comfort.
* **Batch Upload & Queue:** Solves high-volume importer submission surges by supporting single and multi-label processing.
* **Nuanced Verification Logic:** Flexible text comparison algorithm that distinguishes between severe compliance failures and minor capitalization/punctuation variations.
* **Statutory Warning Enforcement:** Strict check logic ensuring mandatory `GOVERNMENT WARNING:` formatting (all caps, bolding, exact statutory text).
